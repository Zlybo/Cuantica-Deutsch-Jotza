Por: Andres Julian Gil Nagles

OS: Windows 10 Pro version 22H2

Lenguaje: Python 3.12.4

IDLE: Pycharm IDLE

El código permite evaluar todas las funciones booleanas de n qubits, determinando si son constantes o balanceadas utilizando el algoritmo de Deutsch-Jozsa. Además, proporciona estadísticas sobre la cantidad total de funciones, funciones balanceadas y constantes, y cuenta la cantidad de unos en cada representación binaria de las funciones.
